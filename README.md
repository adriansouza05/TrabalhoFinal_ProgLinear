## Descrição

Este repositório contém o relatório e a implementação do Trabalho Final de Programação Linear.

O problema trata da escolha de `m` localidades para instalar centros de distribuição, considerando `n` localidades atendidas. Cada localidade possui coordenadas cartesianas, número estimado de viagens semanais e indicação de elegibilidade para receber um centro.

## Objetivos

### Item (a)

Minimizar a maior distância entre uma localidade e o centro de distribuição que a atende.

### Item (b)

Maximizar o total de viagens semanais destinadas a localidades cobertas por pelo menos um centro dentro de um raio `R`.
